This directory supplements, rather than replaces, the October 7 measurements.

negative-control checks from a new isolated Python 3.11 CPU environment.

Cross-host evidence
-------------------
reference/: October 7 recorded nominal traces and receipt from dgxh-2.
fresh-cpu/: October 8 recorded nominal traces and receipt from dgx2-2.
frozen-manifest.json: identical manifest, model, controller and physics hashes.
cross-host.json: the original unchanged 1e-9 atol/rtol gate passed 5/5 cases
with maximum state/velocity/joint-target difference zero and matching physical
contacts. This is five two-second seeded simulation trajectories on these
two hosts. It does not establish general cross-platform determinism or a
long-term CI flake rate. Raw JSON byte hashes differ because wall times differ.
comparison-negative-controls.json: the comparator rejects same-host/wrong-
manifest inputs and detects a joint-target change in a copy of an actual trace.

To independently reproduce the comparison, extract the committed frozen ZIP
into a fresh directory and install its pinned runtime (README CPU instructions).
Run from the repository root with PYTHONPATH unset:
  python scripts/bench/compare_replay_hosts.py --bundle /tmp/FROZEN_BUNDLE \
    --reference results/task-closure-20261008/h2-replay/reference \
    --candidate results/task-closure-20261008/h2-replay/fresh-cpu \
    --out /tmp/NEW_COMPARISON.json
The tool verifies every bundle input and the receipts before comparing traces.
