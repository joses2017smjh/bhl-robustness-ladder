## Projects

### SPUR — Metric-Depth Inference and Model Serving

Built a FastAPI service for single-view and multi-view metric-depth inference, checkpoint validation and calibrated 3D reconstruction. Exported the refiner as split ONNX components with recorded numerical parity checks. Five saved best-validation scores average 0.0445 ± 0.0057 m RMSE on synthetic data; this is not real-orchard accuracy.

Skills: Python, PyTorch, Computer Vision, FastAPI, ONNX Runtime

Repository: https://github.com/joses2017smjh/spur-depth-service

Case study: https://jose-sanchez-portfolio-com.vercel.app/projects/depth-estimation-robotic-pruning/

### BHL Robustness Ladder — Robot Learning and Evaluation

Built experiment infrastructure around Berkeley Humanoid Lite: PPO curricula in Isaac Lab, exported-policy evaluation in MuJoCo, sensor checks and Slurm run records. Evaluations exposed cases where higher training reward did not produce better transfer. The results distinguish learned control, scripted supervision and negative controls; hardware locomotion is not claimed.

Skills: Reinforcement Learning, Robotics, PyTorch, Isaac Lab, MuJoCo

Repository: https://github.com/joses2017smjh/bhl-robustness-ladder

Case study: https://jose-sanchez-portfolio-com.vercel.app/projects/bhl-robustness-ladder/

### Vision-Guided Pruning — RGB-D Control in Isaac Sim

Built camera-based control, sensor and geometry gates, telemetry capture and independent grading for a simulated UR5e in a two-tree orchard. One 20-second run passed all 17 sequence checks; a separate tracking-loss attempt stopped without release. The task uses a known target and rigid-piece release, not learned branch recognition or wood fracture.

Skills: Robotics, Computer Vision, Isaac Sim, OpenCV, RGB-D Sensing

Repository: https://github.com/joses2017smjh/isaac-sim-pruning-workflow

Case study: https://jose-sanchez-portfolio-com.vercel.app/projects/isaac-pruning-workflow/

### MetaNaviT — Research-File Retrieval and Data APIs

Contributed retrieval and data APIs on a six-person team. The frozen 136-query, 61-file benchmark uses hash embeddings and overlap reranking: the full pipeline reaches Recall@50 0.938 and nDCG@10 0.493. BM25 alone retains higher aggregate nDCG@10, making the coverage-versus-ranking tradeoff explicit. Neural-backend or production-corpus performance is not claimed.

Skills: Information Retrieval, Python, FastAPI, PostgreSQL, API Development

Repository: https://github.com/joses2017smjh/MetaNavT

Case study: https://jose-sanchez-portfolio-com.vercel.app/projects/metanavit/
